# 대시보드 화면 계약

운영자가 Alert를 찾고 사유·근거를 읽는 한국어 차콜 화면이다. 탐색은 전체 목록, 조사는 왼쪽 목록/오른쪽 상세, 집중 읽기는 중앙 상세다. 좁은 화면에서는 조사 영역을 세로 배치한다. 보기 전환은 조회·선택·입력·원문 펼치기를 변경하거나 GET을 보내지 않는다.

## 정보와 표시 의미

- level, human_required, 두 점수, recommended_actions는 서버값을 그대로 표시한다. 수준과 검토 요구를 분리하며 INFO/검토 요구 없음을 안전·처리 완료로 표현하지 않는다.
- 점수는 범주별 신호 점수 합계다. 확률·백분율로 바꾸지 않는다. 권장 조치는 제안이다.
- 상세는 평가 사유·검토 요구 → 점수 → signal.reason/evidence → 권장 조치 → 추적 정보 순서다. 생성 요청 trace_id는 body 값이다.
- 평가 사유 원문은 reason_summary, 신호 원문은 signal.reason만 펼친다. 전체 객체·metadata 열람을 만들지 않는다.
- 한글은 정의된 rule/evidence 매핑만 사용하며 미정의 규칙·코드는 서버 원문을 유지한다. 자유 요약이나 재판단을 하지 않는다.

| 입력 상황 | 표시 |
| --- | --- |
| evaluation_integrity_override + error_code=timeout_01 | 요약: 평가 대상의 응답 시간 초과가 보고되었습니다. / 신호: 입력된 실패 코드가 응답 시간 초과를 나타냅니다. |
| latency_high | 입력된 지연 시간이 평가 기준을 초과했습니다. |
| 일반 무신호 INFO의 정의된 원문 | 현재 평가 기준에서 위험 신호 수준이 낮게 분류되었습니다. |
| missing_model_version | 입력된 모델 버전 정보가 없습니다. |

실패 코드·지연은 전달된 입력 사실이며 모니터 서비스 장애나 API 처리 시간으로 설명하지 않는다. timeout 설명을 다른 코드에 재사용하지 않는다. 조합별 매핑의 정확한 조건은 `src/display-contract.mjs`가 소유한다.

| 빈 값/상태 | 화면 문구 |
| --- | --- |
| evidence 값 null | 입력값 없음 + 원래 null; 0/false/빈 문자열과 구분 |
| evidence {} | 표시할 판단 근거가 없습니다. |
| signals [] | 발동된 평가 신호가 없습니다. |
| recommended_actions [] | 제공된 권장 조치가 없습니다. |
| 로딩 | Alert를 불러오는 중입니다. |
| 정상 빈 목록 | 현재 조회 조건에 맞는 Alert가 없습니다. |
| 상세 404 | 해당 Alert를 찾을 수 없습니다. |
| HTTP/연결 실패 | Alert를 불러오지 못했습니다. + 재시도 |
| 필수 필드·타입·JSON·상세 ID 오류 | 응답 데이터를 확인할 수 없습니다. |

빈 근거를 DB 원본 부재로, 빈 신호를 안전으로 해석하지 않는다. 필수 응답의 누락을 0/false/빈 배열로 대체하지 않는다. 목록의 404를 상세 없음으로 처리하지 않는다.

## 스타일과 읽기

| 역할 | 값 |
| --- | --- |
| 배경 / 표면 / 본문 | #191E23 / #20262C / #EDF0F3 |
| 보조 글자 / 경계 / 입력 경계 | #AEB7C0 / #39424C / #697986 |
| 강조 / CRITICAL / WARN | #83B7B0 / #F3A59D / #E7C486 |
| 서체 | Geist·Pretendard, 식별자·수치 Geist Mono |

본문 15px, 주요 라벨·입력 13~14px, 보조 운영 정보 12px를 기준으로 여백과 행 높이를 맞춘다. 목록 사유는 3줄·식별자는 2줄 미리보기이며 상세 원문은 끝까지 읽을 수 있다. 공백 없는 식별자·근거도 줄바꿈한다. 의미는 문자·아이콘·선택선으로도 전달한다.

상세 열기·재시도는 지속되는 상세 제목으로 포커스를 옮긴다. 닫기는 원래 목록 버튼/직접 ID 입력으로, 사라진 경우 보이는 목록 제목으로 복귀한다. 응답 도착은 편집 포커스를 이동하지 않는다. 더보기 버튼은 로딩 중 유지하며 aria-disabled와 controller가 중복 요청을 막는다. 마지막 페이지에서 포커스된 버튼이 사라지면 목록 제목으로 복귀한다.

600px 아래로 스크롤하면 맨 위로 버튼을 표시한다. 키보드로 작동하며 상단 제목 포커스와 즉시 스크롤만 바꾼다. 누적 결과·적용 조건·선택·입력은 보존한다. 상시 사용법 문구는 생략하되 입력 오류 안내는 유지한다.

통계 카드·전체 건수 추정·실시간 차트·검토 완료 기능을 추가하지 않는다. 전체 접근성 인증이나 운영 배포 검증을 완료했다고 표현하지 않는다.
